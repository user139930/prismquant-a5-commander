四種拓撲的差別

A5 是唯一面向使用者的角色，所以「用哪個大腦」不是技術偏好，是成本、審計與偏誤的取捨。以下四種都能跑，切換後下一次生成即生效。

四種拓撲的取捨

我們的選擇

對照實驗

用同一份輸入跑兩種 LLM 拓撲，比對置信度、引用數、延遲與 tokens。沒有 key 時這顆按鈕會誠實地停用。

關注詞

這些詞會影響上游訊號的重排，以及「要盯什麼」裡的提醒。改完下一次生成生效，存在本機 data/prefs.json。

每一份晨報都留檔

proposal §3.4 要求「可重播這個決策」。這裡存的是輸入快照、拓撲與提示詞版本；重播是重跑再比對漂移，不是重播舊畫面。任選兩份可以比較。

A5 已就位，四個代理還在路上
